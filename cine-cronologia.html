Cine Mexicano: Cronología

Las 1,712 películas de la lista maestra, ahora una por una. Haz clic en la banda de una década para entrar a ella y ver cada entrada con su año; pasa el cursor sobre una película para ver su póster. Usa la rueda para acercar y arrastra para desplazarte. Con la vista completa solo se muestran puntos; las fichas aparecen al entrar a una década.

Pasa el cursor sobre una película

Los pósters se cargan al momento desde la API pública de Wikipedia (primero en español, luego en inglés) solo para identificación y no se almacenan en este sitio; para muchas películas poco documentadas no habrá póster. Misma base de datos que el histograma.
